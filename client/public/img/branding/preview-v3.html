Shape B with every gradient removed. Because it is a single-weight stroke, one solid colour is all it needs. Adaptive

One file, no fixed colour: it paints with currentColor and inherits whatever colour the surrounding text has. Note this only works when the SVG is inlined into the page (or used as a CSS mask) — an SVG loaded through <img src> is an isolated document and would fall back to black.
